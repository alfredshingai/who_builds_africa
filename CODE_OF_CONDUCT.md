# Contributor Covenant Code of Conduct 2.1

## Pledge

We pledge to make participation harassment-free for everyone.

## Standards

Positive: empathy, respectful language, constructive feedback, focus on evidence.
Unacceptable: harassment, trolling, personal attacks, publishing private info, bad-faith edits.

## Enforcement

Report to @alfredshingai via email (listed on profile) or GitHub report. Maintainer will review, document, and may remove content or ban contributors.
