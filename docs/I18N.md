# Multilingual - WHO BUILDS AFRICA?

Status: scaffolding - English is authoritative, FR/PT/AR are placeholders requiring human review.

## How it works

- UI strings in `app/locales/{en,fr,pt,ar}.json` - loaded via `fetch(/app/locales/<lang>.json)` in `app/index.html:loadLocale()`
- Language switcher `<select id="lang">` persists to `localStorage wba_lang`, sets `document.documentElement.lang` and `dir` (rtl for ar)
- All claims/sources remain in original language - no auto-translate assumed. `sources.lang` preserved, `verbatim_quote` original.
- Do not use machine translation without human review - per `DATA_METHODOLOGY.md`.

## Adding a language

1. Copy `app/locales/en.json` to `app/locales/<code>.json` (ISO 639-1)
2. Translate values, keep keys, add `// HUMAN REVIEW NEEDED` note until reviewed
3. Add option to `<select id="lang">` in `app/index.html`
4. Test: `python -m http.server` then switch language - check layout, rtl, search placeholder.

## Future
