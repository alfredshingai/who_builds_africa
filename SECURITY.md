# Security Policy

## Reporting

Do not open public issues for sensitive data or vulnerability reports. Contact @alfredshingai privately (GitHub profile) or email.

## Scope

- No personal data stored (orgs/projects only)
- No secrets in repo - use env vars for deploys
- Dependencies pinned via `requirements.txt`; Dependabot enabled (planned)

## Supported versions

`main` only at MVP stage.
